# 📖 Overview

The **Online Cheating Detector** is an AI-powered proctoring system designed to improve the integrity of online examinations. It uses real-time webcam analysis to monitor student behavior and identify suspicious activities such as looking away from the screen, multiple faces, phone usage, and prolonged absence from the camera.

The system provides instant alerts, making online assessments more secure and reliable.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/blackspadesz784/Online-Cheat-Detector.git
```

Move into the project

```bash
cd Online-Cheat-Detector
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python app.py
```
